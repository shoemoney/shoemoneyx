# Code of Conduct

Be decent. Concretely:

- Treat everyone with respect. No harassment, no personal attacks, no discrimination.
- Argue about code and markets, not about people.
- No pump-and-dump promotion, no unsolicited signal selling, no financial advice presented as fact.
- Assume good faith. Ask before escalating.

Maintainers may remove content or contributors that violate this. Report problems privately to the maintainers via the contact in SECURITY.md.
