# Clockwise attention and typing

Nanites follows the actual market orbit clockwise, starting at the top. Each market gets a 1.6-second eased head turn followed by a 1.8-second hold; 18 markets make a 61.2-second circuit. The current coin receives a brighter halo in both the Three.js scene and CSS fallback. The shared orbit helper keeps the direction consistent between renderers. The attention effect does not select markets, open dialogs, or modify trading state.

A soft blue cone and narrow light ray connect the transformed eye to the current coin. The SVG overlay reads the actual eye position and the coin's projected Three.js position (or its CSS fallback position). Light fades in as the head arrives and fades out before the next turn, so it never snaps between coins at full brightness. The eye brightens with the same envelope. Coordinate updates run at up to 30 Hz without reactive page updates on every frame; resizing refreshes the alignment, and the overlay never intercepts input.

The head uses the existing jaw cutout with modest yaw, pitch, and lateral movement. Alternating forearm taps suggest typing on a blue holographic keyboard. Both motions use the same elapsed animation clock, beginning after the nanite formation and its fade finish. Pausing, hiding the tab, or scrolling the robot offscreen preserves the pose. Reduced motion keeps the character still. Replay and market-universe changes reset the scan; routine quote updates do not. Empty market lists leave the robot neutral.

The body and forearms are separate clipped layers of `public/brand/shoegpt-robot-typing-wide.png`. Its head pixels above row 420 are identical to the approved armor robot, preserving the head mask coordinates. The original armor image provides a concealed torso layer behind the moving arms. The particle sampler uses the same typing pose for Nanites; other editions keep the original armor pose. The user requested wider hand spacing; the final pose spreads the hands over a wider 48-key surface, with the fingertips at the key plane.
