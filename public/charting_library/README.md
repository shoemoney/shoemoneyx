# TradingView Charting Library

The TradingView Charting Library is free but cannot be redistributed.

## Setup

1. Apply for access at [tradingview.com/charting-library-docs](https://www.tradingview.com/charting-library-docs)
2. Download your library files
3. Extract them into this directory (`public/charting_library/`)

The library files are gitignored (except this README) so they won't be committed to the repository.
